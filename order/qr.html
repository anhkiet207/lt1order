1. Cấu hình

Lưu ý: điện thoại không mở được đường dẫn file:///C:/.... Muốn quét được thật thì trang phải nằm trên mạng:
• Cách nhanh trong cùng WiFi: mở PowerShell tại thư mục lt1 rồi chạy python -m http.server 8000, lấy IP máy bằng ipconfig, điền vào ô trên dạng http://192.168.1.x:8000/order/index.html.
• Cách công khai: đẩy thư mục order lên GitHub Pages / Netlify rồi dán link https vào.
